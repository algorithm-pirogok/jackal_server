# Шакал онлайн

Настольная игра «Шакал» на двоих через интернет. Сервер считает правила,
браузеры только рисуют. Без сборки, без зависимостей, без npm.

## Как играть

Один из вас открывает сайт, вводит любой код комнаты (например `PIRATE`),
жмёт «Играть» и кидает второму ссылку-приглашение. Второй открывает ссылку и
садится за игру. Третий и далее подключаются зрителями.

Игрок **A** ведёт северную и южную команды, игрок **B** — западную и восточную.
У каждого получается 6 пиратов на двух кораблях. Ход идёт по кругу
север → запад → юг → восток, то есть люди чередуются.

Цвет закреплён за браузером: закрыл вкладку, вернулся по той же ссылке —
садишься за свою же сторону, партия продолжается.

## Запуск локально

```bash
deno task dev
```

Открыть http://localhost:8000. Порт меняется переменной `PORT`, интерфейс —
переменной `HOST` (по умолчанию `0.0.0.0`, то есть видно со всех сетей машины).

Если Deno не установлен:

```bash
curl -fsSL https://deno.land/install.sh | sh
export PATH="$HOME/.deno/bin:$PATH"
```

## Игра по Hamachi (или по локальной сети)

Сервер держит один из игроков на своём ноутбуке, второй заходит к нему в гости —
ни хостинга, ни белого IP не нужно.

1. Оба ставят [Hamachi](https://vpn.net) и входят в одну сеть: первый создаёт её
   кнопкой «Создать новую сеть», второй присоединяется по имени и паролю.
   В окне Hamachi у хозяина появляется адрес вида `25.31.44.7`.
2. Хозяин запускает сервер:

   ```bash
   deno task dev
   ```

   При старте сервер сам печатает адреса, по которым его видно снаружи:

   ```
   Хозяин партии: http://localhost:8000/
   Второму игроку (Hamachi или LAN): http://25.31.44.7:8000/
   ```

3. Хозяин открывает http://localhost:8000, вводит код комнаты и жмёт «Играть».
   Кнопка «Скопировать ссылку» отдаёт ссылку уже с хамачи-адресом
   (`http://25.31.44.7:8000/?room=PIRATE`) — её и надо отправить второму.
4. Второй открывает ссылку в браузере и садится за игру. Hamachi у него должен
   быть подключён к той же сети, иначе адрес 25.x.x.x не резолвится.

Если страница у второго не открывается:

- проверьте, что рядом с хозяином в окне Hamachi горит зелёный кружок
  (жёлтый или синий — туннель не поднялся, помогает «Проверить связь»);
- разрешите `deno` входящие подключения в брандмауэре — Windows спрашивает об
  этом при первом запуске, и по умолчанию отвечает «отмена». Проверить можно
  так: `Параметры Windows → Брандмауэр → Разрешить работу с приложением`;
- если не хочется светить сервер в остальные сети, привяжите его только к
  хамачи-адресу: `HOST=25.31.44.7 deno task dev`.

Партия живёт в памяти процесса: хозяин закрыл терминал — партия кончилась.
Пока сервер жив, оба могут перезагружать вкладку и возвращаться на свою сторону.

## Тесты

```bash
npm test          # или: node --test 'test/*.test.js'
```

97 тестов на встроенном раннере Node: раскладка поля, ходы корабля, цепочки
эффектов, вертушки, ром, капкан, бой, перенос золота, условия победы,
урезание состояния для клиента, слоты комнаты.

Тестам нужен только Node — Deno требуется исключительно для запуска сервера.

## Деплой на Deno Deploy (бесплатно)

Способ проще: залить репозиторий на GitHub, зайти на https://dash.deno.com,
«New Project» → выбрать репозиторий → entrypoint `server.js`. Дальше каждый
push деплоится сам.

Способ из терминала:

```bash
deno install -gArf jsr:@deno/deployctl
export PATH="$HOME/.deno/bin:$PATH"
deployctl deploy --project=<имя-проекта> server.js
```

Первый запуск попросит авторизоваться. Состояние партий живёт в памяти
процесса — деплой новой версии сбрасывает текущие партии.

## Устройство

| Файл | Ответственность |
|---|---|
| `engine/tiles.js` | Каталог клеток и колода из 117 штук |
| `engine/board.js` | Геометрия 13×13, море, берега, раскладка по сиду |
| `engine/state.js` | Начальное состояние: команды, корабли, пираты |
| `engine/moves.js` | Легальные действия активной команды |
| `engine/effects.js` | Эффекты клеток и разрешение цепочек |
| `engine/rules.js` | `applyAction` — единственная точка входа |
| `engine/view.js` | `redact` — вырезает закрытые клетки и сид |
| `engine/room.js` | Слоты игроков и реконнект (движок внедряется извне) |
| `server.js` | Deno: статика и WebSocket-комнаты |
| `web/` | Клиент: сетка, подсветка ходов, счёт, лог |

Клиенту никогда не отправляются типы закрытых клеток и сид раскладки —
подсмотреть остров через devtools нельзя.

Правила и спорные трактовки описаны в
`docs/superpowers/specs/2026-08-18-jackal-online-design.md`.

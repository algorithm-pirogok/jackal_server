# Шакал онлайн — дизайн

Дата: 2026-08-18

## Задача

Онлайн-версия настольной игры «Шакал» для партии двух друзей через интернет.
Графика примитивная, но однозначно читаемая. Хостинг бесплатный.

## Формат партии

- **2 человека.** Игрок A владеет северным и южным берегом, игрок B — западным и
  восточным. То есть у каждого по две команды, стоящие друг напротив друга.
- **4 корабля**, на каждом 3 пирата. У каждого человека 6 пиратов.
- Порядок хода по кругу: N → W → S → E. Чётность даёт чередование людей.
- Монеты обеих команд игрока суммируются в один счёт.
- Команды одного игрока **не могут** бить друг друга.
- Монету можно донести на **любой свой** корабль, не обязательно на родной.

## Поле

- Сетка 13×13.
- Внешнее кольцо (ряды/столбцы 0 и 12) — море.
- Остров: квадрат 11×11 (координаты 1..11) минус четыре угловые клетки =
  **117 клеток**. Крайние ряды острова имеют длину 9.
- Корабль ходит вдоль своего берега по 9 морским клеткам, примыкающим к
  девятиклеточному краю острова. Стартует в середине берега.

## Монеты

16 денежных клеток, всего 37 монет. Распределение: 5 клеток по 1 монете,
5 по 2, 3 по 3, 2 по 4, 1 по 5. (5·1 + 5·2 + 3·3 + 2·4 + 1·5 = 37.)

## Ход

Ход — ровно **одно** действие:

1. Сдвинуть свой корабль на 1 клетку вдоль своего берега.
2. Высадить пирата с корабля на примыкающую клетку берега.
3. Сдвинуть одного пирата на 1 клетку в любом из 8 направлений.

Переход пирата на закрытую клетку открывает её, и эффект применяется немедленно.
Эффекты могут выстраиваться в цепочку (стрелка → лёд → крокодил), цепочка
разрешается сервером до состояния покоя в рамках одного хода.

## Эффекты клеток

- **Пустая** — ничего.
- **Стрелки** — пират обязан продолжить движение в одном из указанных
  направлений; если направлений несколько, выбирает игрок.
- **Деньги** — на клетку выкладываются монеты в указанном количестве.
- **Вертушки** — прохождение занимает несколько ходов: джунгли 2, пустыня 3,
  болото 4, горы 5. Пират стоит на клетке, тратя ходы, затем выходит.
- **Лёд** — пират проезжает ещё одну клетку в том же направлении, которым пришёл.
  Новая клетка открывается и её эффект применяется. Если это море — пират плывёт.
- **Крокодил** — пират возвращается на клетку, с которой пришёл.
- **Бочка рома** — пират пропускает один свой ход.
- **Капкан** — пират застревает, пока на клетку не придёт другой свой пират.
- **Конь** — пират перемещается ходом шахматного коня.
- **Пушка** — пирата выстреливает в море по прямой от центра до края поля.
- **Крепость** — пирата на этой клетке нельзя выбить.
- **Крепость с туземкой** — то же, плюс воскрешает одного погибшего пирата за ход.
- **Воздушный шар** — пират мгновенно переносится на корабль своей команды (той,
  с которой он высадился), а не на второй корабль того же игрока.
- **Людоед** — пират съеден и выбывает; монета остаётся на клетке.
- **Самолёт** — переносит пирата на любую клетку поля; срабатывает один раз за партию.

## Золото

- Пират несёт не более одной монеты.
- С монетой нельзя открывать новые клетки — только по уже открытым.
- С монетой нельзя вступать в бой.
- Класть монету можно только на «стационарные» клетки (не стрелки, не вертушки,
  не спецклетки с переносом).
- С монетой нельзя плавать: в море она тонет.

## Бой

Приход пирата на клетку, где стоит пират противника, отправляет того на его
корабль. Груз побеждённого остаётся на клетке. Пиратов в крепости выбить нельзя.
Пираты одного игрока друг друга не бьют.

## Победа

Игрок, доставивший на свои корабли 19 монет (больше половины от 37), выигрывает
немедленно. Если монеты на острове закончились раньше — побеждает тот, у кого их
больше.

## Архитектура

**Сервер — единственный источник правды.** Клиент шлёт намерение, получает новое
состояние. Причины: закрытые клетки не утекают в devtools, рассинхрон между
браузерами невозможен, реконнект восстанавливает партию.

Отброшенные варианты: сервер-ретранслятор с правилами в обоих браузерах
(дублирование логики и гарантированный рассинхрон на цепочках эффектов);
широковещание полного состояния без редактирования (весь остров виден в консоли).

### Модули

| Файл | Ответственность | Зависит от |
|---|---|---|
| `engine/board.js` | Генерация раскладки 117 клеток по сиду | — |
| `engine/rules.js` | `applyAction(state, playerId, action) → {state, events}` | board.js |
| `engine/view.js` | `redact(state, playerId)` — вырезает закрытые клетки | — |
| `server.js` | Deno: статика + WebSocket-комнаты по коду | engine/* |
| `web/index.html`, `web/app.js` | Рендер 13×13, клики, подсветка ходов | — |

Чистый ESM-JavaScript, без сборки. `engine/` исполняется и в Deno на сервере, и в
`node --test` локально. Deno-специфичен только `server.js` — тонкая обвязка почти
без логики.

### Поток данных

1. Клиент открывает `/?room=XXXX`, поднимает WebSocket.
2. Сервер сажает его в комнату, назначает слот игрока (A или B), шлёт
   `redact(state, playerId)`.
3. Клик по пирату → клиент запрашивает у сервера легальные ходы (или получает их
   вместе с состоянием) → подсветка → клик по клетке → `{type:"move", ...}`.
4. Сервер валидирует, применяет, рассылает обоим новое урезанное состояние и
   список событий для лога.

### Ошибки

- Нелегальное действие → сервер отвечает `{type:"reject", reason}`, состояние не
  меняется. Клиент показывает причину и перерисовывает из состояния сервера.
- Обрыв связи → клиент переподключается по тому же коду комнаты и слоту,
  получает актуальное состояние. Партия живёт в памяти сервера.
- Ход не своего цвета или не в свою очередь → `reject`.

### Графика

CSS-grid 13×13. Клетки — эмодзи на цветном фоне (🐊 🎈 ✈️ 🐴 💰 🍺 🏰, стрелки
символами). Пираты — цветные кружки с номером, монета — точка сверху. Ноль
ассетов.

## Тестирование

TDD на `node --test`:

- Генерация поля: ровно 117 клеток, счётчики каждого типа сходятся, сумма монет 37.
- Каждый эффект клетки — отдельным тестом.
- Цепочки эффектов: стрелка → лёд → крокодил, стрелка → капкан.
- Бой: обычный, в крепости, между командами одного игрока.
- Золото: перенос, запрет открытия клеток, запрет боя, утопление в море.
- Условия победы: досрочная на 19 монетах, по большинству при исчерпании.

Deno Deploy, бесплатный тариф, без засыпания. Требует аккаунт владельца (вход

## Спорные правила — требуют подтверждения игроками

Источники расходятся. Ниже — выбранный вариант; поменять дёшево, всё в одном модуле.

1. **Распределение 21 стрелки.** Взято: 4 одиночных диагональных, 4 двойных
   противоположных прямых, 4 двойных смежных диагональных, 4 четверных прямых,
   5 четверных диагональных. Общее число 21 подтверждено источниками,
   разбивка — нет.
2. **Пустыня и монета.** В части описаний в пустыне монета теряется. Взято:
   монета НЕ теряется, пустыня только задерживает на 3 хода.
3. **Горы.** Взято: простая задержка на 5 ходов. В издании «Остров сокровищ»
   гора многоуровневая, это не реализуется.
4. **Пушка.** Взято: пирата выбрасывает в море по прямой до края поля, дальше он
   плывёт. Вариант с гибелью при встрече с чужим кораблём не реализуется.
5. **Самолёт.** Взято: одноразовый на партию, переносит на любую клетку поля.
6. **Ром.** Взято: пропуск одного хода конкретным пиратом, остальные ходят.
